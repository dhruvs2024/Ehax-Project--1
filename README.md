# Ehax-Project--1
### My Experience While Working on the Project

While working on this project, I had to study several important concepts in C, including **linked lists, file I/O operations, dynamic memory allocation, structures, and typedef**.

Among all these topics, **linked lists were by far the most challenging for me** because they were completely new. I had several logical confusions in the beginning, especially when it came to understanding how nodes are connected and how data is accessed and modified. However, as I continued working on the project and encountered different problems, I gradually understood the concept and became more comfortable implementing it.

Another major challenge I faced was using the **`gets()` function**. It occasionally resulted in segmentation faults, especially when the input exceeded the memory allocated for it. Although the input could sometimes appear to be accepted, the program would eventually crash due to the memory being overwritten. To avoid this issue, I switched to using `scanf()` with **`"%8s"`**, which limits the input to the first eight characters and prevents the user from entering more characters than the allocated space.

Despite these challenges, each problem helped me understand the concepts more deeply. **Debugging the code, identifying my mistakes, and gradually solving the logical issues made the entire process a valuable learning experience.**

Overall, working on this project was a **great first-project experience** for me. It not only helped me strengthen my understanding of C programming but also taught me how to approach unfamiliar concepts, debug problems, and improve my code through continuous practice.
